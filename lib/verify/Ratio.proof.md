# verify.Ratio

*Eudoxus proportion definitions on comparable magnitudes.*

**Source.** euclid — Elements, Book V, Definition 5

## Definition 1 — A magnitude is in the same ratio to a second as a third to a fourth when equimultiples match

**Coordinate.** Ratio · proportion · same ratio means matching equimultiples · **Definition**

*Source: euclid*

> **Goal.** A magnitude is in the same ratio to a second as a third to a fourth when equimultiples match
>
> $$\forall a \in Magnitude \forall b \in Magnitude \forall c \in Magnitude \forall d \in Magnitude\quad ratio(a, b) = ratio(c, d)$$

| | **Proof** | | **Math** |
|:---:|:---|:---:|:---|
| ① | We stipulate same ratio means matching equimultiples for proportion on Ratio — this is a definition, not a derived fact. |  |  |
| ② | This follows directly from the definition: ratio(a, b) equals ratio(c, d). Hence proven. | ② | $ratio(a, b) = ratio(c, d)$ |

`Ratio · proportion · same ratio means matching equimultiples`

## Derived fact 2 — Every magnitude is in the same ratio to itself

**Coordinate.** Ratio · proportion · every magnitude is proportional to itself · **Derived fact**

*Source: euclid*

> **Goal.** Every magnitude is in the same ratio to itself
>
> $$\forall a \in Magnitude\quad ratio(a, a) = ratio(a, a)$$

| | **Proof** | | **Math** |
|:---:|:---|:---:|:---|
| ① | We prove that every magnitude is proportional to itself for proportion on Ratio. |  |  |
| ② | We can deduce that ratio(a, a) equals ratio(a, a). Hence proven. | ② | $ratio(a, a) = ratio(a, a)$ |

`Ratio · proportion · every magnitude is proportional to itself`
