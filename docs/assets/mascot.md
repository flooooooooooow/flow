# Flowy the Hedgehog 🦔

![Flow Mascot](flow-mascot.png)

Meet **Flowy**, the Flow programming language mascot!

## Why a Hedgehog?

- **Spiky but Friendly** - Like Flow's strict type system that protects you
- **Small but Capable** - Compact language with powerful features
- **Nocturnal** - For those late-night coding sessions
- **Rolls into a Ball** - Like how Flow compiles to compact, efficient code

## Colors

The purple color palette represents:
- **Creativity** - Flow enables expressive, creative code
- **Innovation** - Effects, autodiff, and other novel features
- **Calm Focus** - Clean, readable syntax

## Usage

Feel free to use Flowy in:
- Documentation
- Community content
- Presentations about Flow
- Learning materials

Just credit the Flow project!
