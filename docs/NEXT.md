# What's Next for Flow

This page is a navigation surface, not a hand-maintained project snapshot.

The canonical strategic backlog is [ROADMAP.md](../ROADMAP.md). Live
implementation state is in GitHub issues and pull requests. Current repository
health is in CI. Release/stability promises are in [STABILITY.md](../STABILITY.md).

Do not add test counts, example counts, open-issue totals, current failure
lists, or release-state assertions here. Those values age faster than this
document can be maintained.

## Rule

work belongs in the roadmap or GitHub, where it can be assigned, deduplicated,
