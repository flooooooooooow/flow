## Derived fact 1 — 0 + m = m

**Coordinate.** the integers · addition · zero on the left gives the value · **Derived fact**

*Source: landau*

*Built on: zero on the right gives the value, for addition on the integers, order does not matter, for addition on the integers*

> **Goal.** 0 + m = m
>
> $$\forall m \in \mathbb{Z}\quad 0 + m = m$$

| ① | We prove that zero on the left gives the value for addition on the integers. |  |  |

| ③ | We invoke the derived fact governing addition on the integers: order does not matter, for addition on the integers (instantiated for 0, m). |  |  |
| ④ | From step 2 and step 3, this implies 0 plus m equals m. Hence proven. | ④ | $0 + m = m$ |
