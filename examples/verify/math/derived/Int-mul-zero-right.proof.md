## Derived fact 1 — m * 0 = 0

**Coordinate.** the integers · multiplication · zero on the right gives zero · **Derived fact**

*Source: landau*

*Built on: zero on the left gives zero, for multiplication on the integers, order does not matter, for multiplication on the integers*

> **Goal.** m * 0 = 0
>
> $$\forall m \in \mathbb{Z}\quad m \cdot 0 = 0$$

| | **Proof** | | **Math** |
|:---:|:---|:---:|:---|
| ① | We prove that zero on the right gives zero for multiplication on the integers. |  |  |
| ② | We invoke the derived fact governing multiplication on the integers: zero on the left gives zero, for multiplication on the integers (instantiated for m). |  |  |
| ③ | We invoke the derived fact governing multiplication on the integers: order does not matter, for multiplication on the integers (instantiated for m, 0). |  |  |
| ④ | From step 2 and step 3, this implies m times 0 equals 0. Hence proven. | ④ | $m \cdot 0 = 0$ |
