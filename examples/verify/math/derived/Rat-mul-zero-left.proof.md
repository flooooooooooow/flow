## Derived fact 1 — 0 * q = 0

**Coordinate.** Rat · multiplication · zero on the left gives zero · **Derived fact**

*Source: landau*

*Built on: zero is the right identity, for addition on Rat, one is the right identity, for multiplication on Rat*

> **Goal.** 0 * q = 0
>
> $$\forall q \in Rat\quad 0 \cdot q = 0$$

| | **Proof** | | **Math** |
|:---:|:---|:---:|:---|
| ① | We prove that zero on the left gives zero for multiplication on Rat. |  |  |
| ② | We invoke the definitional clause governing addition on Rat: zero is the right identity, for addition on Rat (instantiated for q). |  |  |
| ③ | We invoke the derived fact governing multiplication on Rat: one is the right identity, for multiplication on Rat (instantiated for 0). |  |  |
| ④ | From step 2 and step 3, this implies 0 times q equals 0. Hence proven. | ④ | $0 \cdot q = 0$ |
