Equal summands stay equal when the same term is added on the right.\\[0.5em]
\textbf{Source.} leibniz — https://en.wikipedia.org/wiki/Substitution\_(logic)\\[0.5em]
\bigskip
\noindent{\large \textbf{Derived fact 1.} \textit{From a = b we deduce a + c = b + c, by induction on c} \hfill equality \cdot equality \cdot equal terms add the same on the right}\par
\smallskip\noindent\textit{Coordinate: equality \cdot equality \cdot equal terms add the same on the right}\par
\smallskip\noindent\textit{Source: peano/induction — Gries \& Schneider, Ch. 3}\par
\smallskip\noindent\textit{Built on: adding zero on the right does not change the number, adding one more on the right bumps the sum by one}\par
\medskip
\noindent\textbf{Goal.} From a = b we deduce a + c = b + c, by induction on c\par
\noindent$\displaystyle \forall a \in \mathbb{N} \forall b \in \mathbb{N} \forall c \in \mathbb{N}\quad a + c = b + c$\par
