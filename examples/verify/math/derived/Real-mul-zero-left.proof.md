## Derived fact 1 — 0 * x = 0

**Coordinate.** the real numbers · multiplication · zero on the left gives zero · **Derived fact**

*Source: landau*

*Built on: zero is the right identity, for addition on the real numbers, one is the right identity, for multiplication on the real numbers*

> **Goal.** 0 * x = 0
>
> $$\forall x \in \mathbb{R}\quad 0 \cdot x = 0$$

| | **Proof** | | **Math** |
|:---:|:---|:---:|:---|
| ① | We prove that zero on the left gives zero for multiplication on the real numbers. |  |  |
| ② | We invoke the definitional clause governing addition on the real numbers: zero is the right identity, for addition on the real numbers (instantiated for x). |  |  |
| ③ | We invoke the derived fact governing multiplication on the real numbers: one is the right identity, for multiplication on the real numbers (instantiated for 0). |  |  |
| ④ | From step 2 and step 3, this implies 0 times x equals 0. Hence proven. | ④ | $0 \cdot x = 0$ |
