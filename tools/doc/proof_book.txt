# `== <id> <title>` starts a part. Each following line is a .flow file,
# relative to the repository root. Theorems are numbered across the whole
# book in this order. `@manifest <dir>` reads <dir>/MANIFEST.txt, or the
# sorted prop-*.flow files in <dir> when there is no manifest.
# `flow doc basic-bundle` prints the `basic` part and
# `flow doc geometry-bundle` prints `euclid-i`.
