🔬 What's the difference?

WASM demos: Flow → C → Emscripten → .wasm bytecode → Browser WASM engine → Native execution

JS playground: Flow → JavaScript → Browser JS engine. Faster to iterate, but not native performance.

Compile Your Own

Compile any Flow file to WebAssembly: 

$ python3 flow_wasm.py my_program.flow -o output/
