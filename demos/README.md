# Demos

Runnable graphics / Vulkan / UI demos for Flow.

| Path | What |
|------|------|
| `demos/*.flow` packages (`vulkan_*`, `ui_*`) | Native graphics demos |
| [`index.html`](index.html) | Gallery page (links into `wasm/` + `docs/playground/`) |
| [`docs/demos/`](../docs/demos/) | Writeups / media (e.g. Chetris) — not runnable packages |
| [`wasm/wasm_examples/`](../wasm/wasm_examples/) | Browser WASM gallery |
| [`docs/playground/`](../docs/playground/) | In-browser Flow playground |

Rebuild Vulkan binaries locally; checked-in `.spv` / Mach-O outputs are gitignored.
