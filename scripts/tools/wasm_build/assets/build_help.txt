usage: flow tool wasm_build build [-h] [--out OUT] [--name NAME] [--title TITLE]
                                  [--backend {c,mlir}] [--preload HOST@VFS] [--link PATH]
                                  [--initial-memory INITIAL_MEMORY]
                                  [--asyncify-stack-size ASYNCIFY_STACK_SIZE] [-O LEVEL]
                                  [--emcc-flag FLAG] [--threads] [--workers WORKERS]
                                  [--timeout TIMEOUT] [--keep-c] [--json]
                                  program

Compile one Flow program to a runnable WebAssembly page.

positional arguments:
  program               path to a .flow program

options:
  -h, --help            show this help message and exit
  --out OUT             output directory
  --name NAME           module basename
  --title TITLE         page title
  --backend {c,mlir}    CPU codegen: c (default) or mlir
                        (Flow→MLIR→LLVM→emcc). Also accepts FLOW_CPU_BACKEND.
  --preload HOST@VFS    emcc --preload-file mapping (repeatable). Enables
                        FORCE_FILESYSTEM. Works for both --backend=c and
                        --backend=mlir (#225).
  --link PATH           extra C/runtime file to pass to emcc (repeatable).
                        Cocoa .m/.mm are skipped. Example:
                        runtime/flow_rt_support.c
  --initial-memory INITIAL_MEMORY
                        emcc -sINITIAL_MEMORY (default 32MB; doom-scale often
                        64MB)
  --asyncify-stack-size ASYNCIFY_STACK_SIZE
                        emcc -sASYNCIFY_STACK_SIZE when gfx is linked (default
                        32768)
  -O LEVEL              emcc optimisation level: -O2 (default), or -O -O1 /
                        -O2
  --emcc-flag FLAG      extra flag passed through to emcc (repeatable).
                        Example: --emcc-flag=-DNORMALUNIX
  --threads             build on real pthreads (-pthread over
                        SharedArrayBuffer, PROXY_TO_PTHREAD). The page ships a
                        COI service worker because the browser only allows SAB
                        on cross-origin-isolated pages.
  --workers WORKERS     pthread pool size / shard count for --threads (default
                        8)
  --timeout TIMEOUT
  --keep-c              keep the generated C / LLVM IR next to the output
  --json                print the result as JSON
