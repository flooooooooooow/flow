## Decision authority

| Domain | Who decides |
|--------|-------------|
| Language design & syntax | Maintainer (human final) |
| Implementation & refactors | Contributors (maintainer approves) |
| Security advisories | Maintainer |
| Releases & version tags | Maintainer |

Design questions that need a human call are logged in
[`docs/project/Questions.md`](docs/project/Questions.md).

## Roadmap

Strategic priorities live in [`ROADMAP.md`](ROADMAP.md). Day-to-day issues
are tracked on GitHub with labels (`bug`, `enhancement`, `self-hosting`, …).

## Releases

- Semantic versioning: `MAJOR.MINOR.PATCH` (`v0.8.0`, …)
- Changelog: [`docs/project/CHANGELOG.md`](docs/project/CHANGELOG.md)
- Artifacts: GitHub Releases (source tarball/zip + SHA256)
- Docs: https://flooooooooooow.github.io/flow/ (published from `main`)
