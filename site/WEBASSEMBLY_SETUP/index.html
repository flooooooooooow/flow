    FLOW WebAssembly Setup Guide

    🌐 WebAssembly Interactive Demos

    FLOW now supports WebAssembly compilation for browser-based execution! Here's how to get the interactive demos working:

    Quick Start

    1. Try the JavaScript Demo (No Setup Required) 

      # Open the interactive JavaScript demo
open docs/examples/web_interactive_demo.html

    2. Build Real WebAssembly (Requires Emscripten) 

      # Install Emscripten WebAssembly compiler
git clone https://github.com/emscripten-core/emsdk.git
cd emsdk
./emsdk install latest
./emsdk activate latest
source ./emsdk_env.sh
cd ..

# Build WebAssembly demo
./build_wasm_demo.sh

# Open in browser
open web_demo_wasm.html

    Available Demos

    1. JavaScript Interactive Demo

    • File: docs/examples/web_interactive_demo.html
    • Features:
    • ✅ Write and run FLOW code in browser
    • ✅ Multiple examples (Hello World, Fibonacci, Structs, SIMD)
    • ✅ Custom code editor
    • ✅ Real-time output simulation
    • ✅ No setup required

    2. Real WebAssembly Demo

    • Files: Generated by build_wasm_demo.sh
    • Features:
    • ✅ Actual WebAssembly execution
    • ✅ High-performance native code
    • ✅ Real FLOW → C → WASM compilation
    • ✅ Browser-based execution
    • 🚧 Requires Emscripten setup

    Demo Features

    ✅ Working Features

    • Static Typing: Full type checking and inference
    • Functions: Function definitions and calls
    • Structs: Data structures with field access
    • SIMD: Vector operations (vec4, etc.)
    • Control Flow: if, while, for loops
    • WebAssembly: Real browser execution

    🚧 Advanced Features

    • GPU Computing: Metal/CUDA integration (native only)
    • Effects System: Algebraic effects (experimental)
    • Module System: Import/export (experimental)

    Example Code

    Hello World

    function main() -> i32 {
    print("Hello, World!")
    print("🌐 Running in browser!")
    return 0
}

    Fibonacci

    function fibonacci(n: i32) -> i32 {
    if n <= 1 {
        return n
    }
    return fibonacci(n - 1) + fibonacci(n - 2)
}

function main() -> i32 {
    let result: i32 = fibonacci(10)
    print("Fibonacci(10) = " + result)
    return 0
}

    Structs

    struct Point {
    x: f32,
    y: f32
}

function main() -> i32 {
    let p: Point = Point { x: 10.5, y: 20.5 }
    print("Point: (" + p.x + ", " + p.y + ")")
    return 0
}

    SIMD Vectors

    function main() -> i32 {
    let v1: vec4<f32> = <1.0, 2.0, 3.0, 4.0>
    let v2: vec4<f32> = <0.5, 1.5, 2.5, 3.5>
    let result: vec4<f32> = v1 + v2
    print("Result: <" + result + ">")
    return 0
}

    Troubleshooting

    WebAssembly Build Issues

    # If Emscripten not found, install it:
curl -L https://github.com/emscripten-core/emsdk/archive/main.zip > emsdk.zip
unzip emsdk.zip
cd emsdk
./emsdk install latest
./emsdk activate latest
source ./emsdk_env.sh

    Browser Issues

    • Use Chrome, Firefox, or Safari (modern versions)
    • Enable WebAssembly in browser settings
    • Check browser console for errors

    Performance

    • JavaScript demo: Simulated execution (educational)
    • WebAssembly demo: Real native performance
    • For production: Use native FLOW compiler

    FLOW Code → C Code → WebAssembly → Browser

  Parser   MLIR Gen   Emscripten  JavaScript
     ↓         ↓           ↓         ↓
   AST    Optimized    .wasm     .js
