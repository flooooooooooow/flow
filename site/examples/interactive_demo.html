🛠️ Try It Yourself

Run FLOW examples locally with these commands:

# Run a specific example
./flow run examples/fibonacci.flow

# Run all tests
./flow test

# List available examples
./flow examples
Note: FLOW compiles to C for maximum performance and portability. WebAssembly support is now available! Run ./build_wasm_demo.sh to create real WASM binaries.

📖 About FLOW

FLOW is a modern programming language that combines the safety of static typing with the expressiveness of functional programming. It features first-class GPU computing, advanced effects systems, and compiles to high-performance native code.

Current Status: Version 0.2.0 with Metal GPU integration and comprehensive documentation.
